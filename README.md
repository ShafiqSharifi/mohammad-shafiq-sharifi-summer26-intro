## Weather Lookup App

The Weather Lookup page was created as part of Lesson 10. It uses the free Open-Meteo APIs and does not require an API key.

[Open the Weather App](https://shafiqsharifi.github.io/mohammad-shafiq-sharifi-summer26-intro/openapi.html)

### Features

- Search for a city by name
- Convert a city name into latitude and longitude coordinates
- Retrieve the city’s current temperature in Fahrenheit
- Retrieve the current weather code and display it as readable text
- Display one weather result at a time
- Show an error message when a city cannot be found

### How It Works

1. Enter a city name, such as `Modesto` or `Chicago`.
2. Click **Search**.
3. The app uses the Open-Meteo Geocoding API to find the city’s coordinates.
4. Click **Get City Temperature** or **Get City Condition**.
5. The app sends a request to the Open-Meteo Forecast API and displays the selected result.

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in a browser or use the Live Server extension.
4. Select **Weather App** from the navigation menu to test the weather lookup.
